# Agent protocol

The canonical executable guidance is `skills/knowledge-forest/SKILL.md`

Agents may use web search, academic indexes, official documentation, course catalogs, connected drives, or organization-specific systems through adapters

An adapter may discover candidates; it does not waive the audit contract

## Roles

- intake normalizer
- taxonomy scout
- curriculum architect
- resource verifier
- frontier researcher
- adversarial auditor
- deterministic integrator
- experience evaluator

One agent may perform several roles; the artifacts and gates remain separate

## Write boundary

Research agents write candidates and manifests

The deterministic integrator writes the resolved bundle only after validation

The production renderer never consumes raw model output
