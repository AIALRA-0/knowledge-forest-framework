# Quality gates

## Round 1; structure

- coverage contract exists
- domains are explicit
- ids are unique and stable
- prerequisites exist and are acyclic
- compound titles enter review
- primary resources are complete works
- acceptance artifacts have observable criteria
- high-risk domains carry safety boundaries

## Round 2; evidence

- resource URLs are reachable
- authoritative source preference is documented
- access class and licensing are known
- frontier positions have claim-level support
- each node has exactly three frontier positions
- the rolling evidence window is enforced
- duplicates and weak mirrors enter review

## Round 3; experience

- vague novice goal
- prior-skilled practitioner
- cross-domain goal
- high-risk goal
- return visit with saved progress
- changed requirement with correction memory
- unavailable resource recovery
- desktop and mobile layouts

The experience round records observed friction and the change made in response
