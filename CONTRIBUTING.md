# Contributing

Use a focused pull request

Explain:

- the learner or maintainer problem
- the affected contract
- migration impact
- evidence and licensing
- deterministic checks
- realistic user journey

Changes to schemas, correction defaults, safety policy, audit rules, or workflows require a migration note and focused review

Do not copy content or code from a source whose license is incompatible with Apache-2.0 and CC BY 4.0
