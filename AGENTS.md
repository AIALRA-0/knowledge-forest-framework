# Knowledge Forest agent contract

When a user asks for a learning forest, follow `skills/knowledge-forest/SKILL.md`

Never publish a forest directly from a first-pass model response

Every release must contain a validated `ForestBundle`, provenance, an audit report, a review queue, and a realistic user-journey review

User corrections are durable requirements; add each correction to the learner brief with a stable id and a regression check; never make the user repeat an accepted correction

Do not copy private repositories, local paths, credentials, personal progress, restricted course files, or production configuration into a public instance
