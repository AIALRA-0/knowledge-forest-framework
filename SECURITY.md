# Security policy

Report a vulnerability through GitHub private vulnerability reporting when available

Do not open a public issue containing credentials, personal information, private repository data, restricted course files, or production infrastructure details

## Supported releases

The latest minor release receives security fixes during the `0.x` period

## Public release controls

- secret and high-entropy scanning
- local path, host, email, address, and private course record scanning
- dependency review
- pinned workflow dependencies
- least-privilege workflow permissions
- link-only treatment for third-party learning resources by default
- no automatic private-to-public synchronization
